# Tsebo Setai — Personal Portfolio Website

## Project Overview

This project is a personal portfolio website developed as part of the Web Development assignment for the System Development programme at Gauteng City College.

The website introduces me, presents my technical skills, highlights projects and learning activities, provides information about my education, and offers a contact section.

The goal of this project is to demonstrate my understanding of front-end web development using HTML5, CSS3, and JavaScript.

## Technologies Used

* **HTML5** — website structure and content.
* **CSS3** — layout, styling, responsive design, animations, and themes.
* **JavaScript** — interactive features and client-side functionality.
* **Google Fonts** — typography.

## Features

* Responsive layout for desktop, tablet, and mobile screens.
* Home section with an animated introduction.
* About Me section.
* Technical skills section with animated progress indicators.
* Projects section with project filtering.
* Education timeline.
* Contact form with client-side validation.
* Dark and light theme toggle.
* Mobile navigation menu.
* Animated counters and scroll-reveal effects.
* Live South African Standard Time clock.
* Scroll-to-top control.

## How to Run the Project Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, open the folder in Visual Studio Code and use a local development server.

No build tools or framework installation are required for the basic version of this project.
